# Main Theme
1. Linear scan of array (1-D and 2-D) using *indeces*
2. Use *hashmaps/hashsets* strategically to record seen elements to build up the solution

# Procedure
1. identify what needs to be tracked (book-kept)
2. Design how tracking is done (e.g. in *Valid Sudoku*, will track 
    - row[0] ~ row[8]
    - col[0] ~ col[8]
    - square[0] ~ square[8])
